# راهنمای پروژه استودیوی سه‌بعدی نیلپر

این بسته شامل کد کامل صفحه، مدل اصلی مبل، بافت‌های داخل GLB، نور HDR، فونت، کتابخانه‌ها و فایل‌های رندر و حذف نویز است.

## اجرای محلی روی ویندوز
1. فایل ZIP را کامل Extract کنید.
2. Node.js باید روی کامپیوتر نصب باشد.
3. فایل START-WINDOWS.cmd را اجرا کنید و پنجره‌اش را باز نگه دارید.
4. در مرورگر آدرس http://127.0.0.1:4178 را باز کنید.

روش جایگزین: در پوشه پروژه ترمینال باز کنید و دستور زیر را بزنید:
```
node server.mjs
```
برای اجرای این نسخه نیازی به npm install یا دریافت کتابخانه از CDN نیست.
بازکردن مستقیم index.html با دابل‌کلیک کافی نیست؛ صفحه باید از سرور محلی یا هاست باز شود.

## بارگذاری روی هاست
تمام محتویات پوشه dist را روی هاست استاتیک دارای HTTPS قرار دهید.
صفحه از index.html اجرا می‌شود. ساختار پوشه assets و vendor را حفظ کنید.
فایل vercel.json برای انتشار احتمالی روی Vercel هم در بسته وجود دارد؛ این بسته هنوز روی Vercel منتشر نشده است.

## فایل‌های اصلی
- dist/index.html: ساختار صفحه و متن‌ها
- dist/style.css: طراحی و چیدمان موبایل و دسکتاپ
- dist/app.js: صحنه سه‌بعدی، متریال، نور، سایه، دوربین و کنترل‌ها
- dist/assets/Nilper_Final-optimized.glb: فایل اصلی مبل بدون تغییر
- dist/assets/studio.hdr: نور محیط استودیو
- dist/assets/denoise.tza: وزن‌های حذف نویز
- dist/vendor: کتابخانه‌های لازم و مجوزها
- server.mjs: سرور ساده اجرای محلی
- README.md: توضیحات فنی و منابع
- QA.md: بررسی‌های انجام‌شده و محدودیت‌های تست

## کیفیت تصویر
حالت روان برای چرخش و بررسی مبل است.
حالت رندر دقیق از Path Tracing استفاده می‌کند و به WebGPU نیاز دارد. دوربین را ثابت نگه دارید تا تصویر شفاف‌تر شود؛ سرعت به کارت گرافیک وابسته است.
در مرورگرهای فاقد WebGPU، حالت روان با WebGL2 در نظر گرفته شده است.
کلید سازه فقط پارچه‌های موجود در همین مدل را مخفی می‌کند.
تغییر رنگ/جنس و AR در این نسخه پیاده‌سازی نشده‌اند.

این بسته تمام فایل‌های لازم برای اجرا را دارد. پوشه‌های موقت، تاریخچه Git و node_modules که نسخه‌های تکراری کتابخانه‌های موجود در dist/vendor هستند، در ZIP نیستند.
